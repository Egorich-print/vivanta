# Project Roadmap

This document outlines the roadmap for the Vivanta project, detailing the planned milestones and features.

## Vision

Vivanta aims to be a universal operating system platform that adapts to the user and hardware, not the other way around. It prioritizes seamless hardware evolution and a friction-free user experience.

## Milestones

### Milestone 1: Foundation (Current Focus)

*   **Device Support**: Xiaomi Redmi Note 7 (lavender) as the first supported device.
*   **Core Architecture**: Establish the hybrid kernel, basic runtime, and initial build system.
*   **Documentation**: Set up project structure, ADRs, RFCs, and initial design documents.
*   **Goals**: Architecture-first repository, organized documentation, clear vision.

### Milestone 2: Minimum Viable Product (MVP)

*   **Kernel Enhancements**: Implement core process and memory management, dynamic module loading.
*   **Runtime**: Basic system libraries and execution environment.
*   **Graphics**: Initial support for Wayland and Vulkan.
*   **Package Management**: Basic package installation and dependency handling.
*   **Target Architectures**: Initial support for x86_64 and ARM64.

### Milestone 3: Feature Expansion

*   **Containerization**: Implementation of Linux and Android container support.
*   **Adaptive UI**: Development of different UI modes (Mobile, Desktop).
*   **Hardware Adaptation**: Refine hardware detection and profile management.
*   **Application Ecosystem**: Establish mechanisms for application distribution and AOT compilation.

### Milestone 4: Ecosystem Growth

*   **Broad Hardware Support**: Expand support to a wider range of devices and architectures.
*   **Developer Tools**: Robust tooling for application development and system customization.
*   **Community Building**: Foster an active developer and user community.

## Future Considerations

*   Advanced security features and hardening.
*   Integration with emerging technologies (e.g., AR/VR).
*   Long-term maintainability and evolution strategies.
