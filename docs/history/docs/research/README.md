# Research Directory

This directory is intended for research notes, findings, and experiments related to the development of Theseus OS.

## Areas of Research

*   **Kernel Architectures**: Microkernel vs. Monolithic vs. Hybrid approaches.
*   **Memory Safety Languages**: Rust's suitability for OS development.
*   **Cross-Compilation Toolchains**: LLVM, GCC, and their capabilities.
*   **Containerization Technologies**: Evaluating existing solutions and potential for custom implementations.
*   **Graphics APIs**: Vulkan, OpenGL, Metal, DirectX.
*   **Filesystem Technologies**: BTRFS, XFS, F2FS, ZFS.
*   **Security Models**: Capabilities, SELinux, AppArmor.
*   **Bootloaders**: GRUB, Limine, U-Boot.
