# Concepts

This directory houses various ideas and concepts related to the Vivanta project. Concepts can range from high-level philosophical ideas to potential system components. They serve as a starting point for further discussion, research, and potential formalization into RFCs or ADRs.

## Concept Stages

*   **Active**: Concepts currently under active discussion and development.
*   **Incubating**: Ideas in early stages, requiring more research.
*   **Archived**: Concepts no longer actively pursued.
*   **Rejected**: Ideas that have been formally rejected after consideration.

Please refer to the respective subdirectories for documented concepts.
