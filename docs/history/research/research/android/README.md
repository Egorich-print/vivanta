# Android Research

This directory contains research related to Android application compatibility and integration.

## Topics

*   **Compatibility Layer**: Investigating methods to run Android applications (e.g., existing solutions like Waydroid, or custom approaches).
*   **Package Format (.apk)**: Understanding the structure and requirements for running APKs.
*   **Runtime Environment**: Requirements for the Android runtime (ART/Dalvik).
*   **Permissions and Security**: How Android app permissions can be managed within Theseus OS.
