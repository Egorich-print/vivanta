# Open Architectural Questions

This directory contains questions that need to be addressed as part of the architectural design process. These questions are precursors to formal RFCs and serve to identify areas requiring focused discussion and research.

## Process

1.  **Identify a Question**: Add a new Markdown file for each significant open question.
2.  **Document Context**: Briefly explain the background and relevance of the question.
3.  **Outline Options/Candidates**: If applicable, list potential answers or approaches.
4.  **Define Evaluation Criteria**: Specify how potential answers will be evaluated.
5.  **Target Milestone**: Indicate when a decision is expected (e.g., by which RFC or milestone).
6.  **Discussion**: Facilitate discussion around the question.
7.  **Resolution**: Once resolved, the question may lead to an RFC, ADR, or be marked as addressed.
