## Детальный анализ

### 1. Xiaomi Poco F1 — ИДЕАЛЬНЫЙ КЛАСТЕРНЫЙ УЗЕЛ

**Цены (Авито, Москва):**
- Б/у рабочий: 2,900-3,800 ₽
- 6/64: ~3,000-3,200 ₽ (самый дешёвый)
- 6/128: ~3,800 ₽

**SoC: Qualcomm Snapdragon 845**
- CPU: 8x Kryo 385 (4x A75 @ 2.8 GHz + 4x A55 @ 1.8 GHz)
- GPU: Adreno 630
- NPU: Hexagon 685 DSP
- Process: 10nm
- GeekBench 6: SC 563 / MC 2,006
- AnTuTu: ~570,000-600,000

**Linux-поддержка: ОТЛИЧНАЯ**
- postmarketOS: полная поддержка (device: xiaomi-beryllium)
- Ядро: linux-postmarketos-qcom-sdm845 (6.x)
- Работает: SSH, WiFi, GPU, модем, дисплей, тачскрин
- Bootloader unlock: через Xiaomi tool (30-дневное ожидание!)
- EDL mode: доступен
- UART: есть test points

**Разборка:**
- Корпус снимается достаточно легко
- Плата доступна после снятия задней крышки
- Батарея отсоединяется
- Пассивное охлаждение: металлический экран/каркас serves as heat sink

**Питание без батареи:**
- Возможна эмуляция батареи (battery emulator)
- Нужно: 3.4-4.4V на (+)/(-), резистор ~2350 Ом на (T)/(-) для термистора
- PMIC Qualcomm PMI8998 поддерживает USB DPDM

**Плюсы:**
- Самая низкая цена за SoC class
- Лучшая Linux поддержка
- Массовость — легко купить 10-50 штук
- Хорошая документация (community)
- UFS 2.1 storage

**Минусы:**
- Bootloader unlock требует Windows + ожидание 30 дней
- Процессор 2018 года (10nm)
- Нет USB 3.0 (только USB 2.0 Type-C)
- Пластиковый корпус (хуже теплоотвод)

## Питание без батареи: технические детали

Для всех Qualcomm-устройств необходим **battery emulator**:

### Схема подключения
```
Внешний PSU (5V) → Диод (1N4007, -0.7V) → ~4.3V
                     ↓
              (+) батарейный контакт
              
              (-) → GND
              
              (T) → Резистор 2350 Ом к GND (эмуляция термистора)
```

### Важные моменты
1. **PMIC Qualcomm** (PMI8998 для SD845, PM8150 для SD855):
   - Поддержка USB DPDM для negotiate power
   - Некоторые устройства требуют battery для boot
   - Рекомендуется: battery emulator board вместо прямого подключения

2. **Рекомендуемые решения:**
   - Готовые battery emulator (есть на AliExpress, ~500-1000 ₽)
   - Кастомная плата на основе TP4056 + resistor divider
   - Заряженная старая батарея как буфер (проще, но less reliable)

3. **Мощность:**
   - SD845: ~2.6W под нагрузкой, ~1.2W idle
   - SD855/860/870: ~2-3W под нагрузкой
   - Один блок питания 12V/5A может питать 10-15 узлов

## Сценарии использования

### Режим A — Распределённые сервисы (10 узлов Poco F1)

```
Узел 1-2: LLM inference (llama.cpp, 7B models)
Узел 3-4: Vision pipeline (ONNX Runtime)
Узел 5-6: Speech-to-text (Whisper)
Узел 7: Database (SQLite/PostgreSQL)
Узел 8: Message queue (Redis)
Узел 9-10: Load balancer + monitoring
```

**Общая RAM:** 60 GB  
**Общее хранилище:** 640 GB (10x 64GB eMMC)

### Режим B — Объединение ресурсов

Для распределённого inference модели больше RAM одного устройства:
- **Ray** или **MPI** для распределения вычислений
- **Pipeline parallelism**: разделение слоёв модели по узлам
- **Tensor parallelism**: разделение матриц по узлам

**Ограничения:**
- Сеть: WiFi (max ~150 Mbit/s) — bottleneck
- Рекомендация: USB-Ethernet адаптеры для каждого узла
- Kubernetes/Docker Swarm для оркестрации

## Рекомендации

### Для PoC (Proof of Concept): 3-5 узлов Poco F1
- Бюджет: ~15,000-25,000 ₽
- Цель: проверка концепции, benchmarking

### Для продакшена: 10-20 узлов Poco X3 Pro (8/256)
- Бюджет: ~65,000-136,000 ₽
- Цель: реальные рабочие нагрузки

### Критические риски
1. **Bootloader unlock**: Xiaomi требует Windows + 30 дней ожидания
2. **Надёжность**: consumer-grade hardware не рассчитан на 24/7
3. **Тепловыделение**: нужен active cooling при sustained load
4. **Сеть**: WiFi inadequate для serious clustering
