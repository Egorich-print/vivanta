## Objectives

1. Capture authoritative device identity + partition geometry for the
   `whyred-pve-uefi` flashing pipeline.
2. Determine bootloader lock state and anti-rollback posture.
3. Establish which fastboot verbs are safe on MIUI ABL.

## Results

### 1. Full variable dump — SUCCESS

`fastboot getvar all` returned the complete set: lock state, MiUL token,
anti-rollback version, eMMC geometry, and per-partition type/size pairs
(see bootloader.md / partitions.md). Key facts:

- **unlocked:no** — locked; pipeline artifacts are ready but blocked on Mi Unlock
- **anti:4** — anti-rollback fuse at v4
- userdata = 0xCD77F7E00 (54.9 GiB) ext4 — rootfs target confirmed ample
- boot = 64 MiB raw — matches our payload-packer budget exactly
- A-only layout (no slot variables), no dtbo partition

### 2. Identity discrepancy — DOCUMENTED

Directive serial "19680/68UA04603" does not match USB enumeration serial
`4699bca9`. The directive string is not a valid fastboot serial format
(likely an internal inventory number). Fleet table updated:
whyred → `4699bca9`.

### 3. Incident: ABL wedge on unsupported OEM command

| | |
|---|---|
| Command | `fastboot oem device-info` |
| Symptom | No response; subsequent getvar commands time out while USB still enumerates |
| Root cause (hypothesis) | MIUI ABL's fastboot dispatcher handles unknown `oem` verbs by waiting on a reply object that is never signalled — single-threaded command loop stays blocked |
| Recovery | Physical: force reboot to bootloader (Vol− + Power ≈10 s). Not recoverable over USB from host side |
| Rule adopted | Read lock state ONLY via `getvar unlocked`; never send undocumented `oem *` to this ABL. MiToolbox oem_unlock_probe must treat non-response as expected-failure and reconnect |

## Implications for whyred-pve-uefi pipeline

1. dist/ artifacts unchanged and validated against measured geometry
   (payload 6.3 MB < 64 MiB budget; rootfs 8 GiB < 54.9 GiB).
2. flash_all.sh product check (`getvar product`) remains valid but must run
   BEFORE any oem probing.
3. Owner prerequisite before first flash: Mi Unlock (Windows tool,
   account binding period). Documented in FLASHING_GUIDE.md §1.
