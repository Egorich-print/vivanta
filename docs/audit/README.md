## Чего здесь нет

Запрос на внешнее ревью — не аудит. Такой документ лежит в архиве:
[`docs/history/audit-prompts/Independent_Architecture_Audit.prompt-template.md`](../history/audit-prompts/Independent_Architecture_Audit.prompt-template.md).

Это шаблон промпта для внешних LLM-ревьюеров (ChatGPT, Gemini, Grok,
DeepSeek) **без ответов**: он заканчивается вопросами «Overall architectural
quality (1–10)» и «Would you approve this roadmap…», на которые в файле никто
не ответил. Пока он лежал рядом с двумя настоящими аудитами, он портил смысл
всейй папки. Содержимое сохранено дословно как исторический артефакт; оценки
из него не выводите — они не про эту папку и не про текущее состояние ядра.
